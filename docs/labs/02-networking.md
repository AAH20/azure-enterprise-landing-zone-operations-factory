# Lab 2: Enterprise networking

1. Deploy hub and spoke VNets and validate peering state.
2. Inspect effective NSG rules and explain the default platform rules.
3. Verify Private DNS linkage and the blob private-endpoint connection.
4. Simulate incorrect DNS, overlapping CIDR and missing peering cases locally or in `what-if`.
5. Design the production route table, firewall, VPN/ExpressRoute and egress path without deploying expensive gateways.

Evidence: resource topology, peering state, DNS records, expected failure and troubleshooting timeline.
