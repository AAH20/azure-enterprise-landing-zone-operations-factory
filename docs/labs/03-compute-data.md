# Lab 3: Compute and data decisions

Score VM, VM Scale Sets, App Service, Container Apps, AKS and Functions against traffic shape, portability, operations, scaling, security and cost. Score Storage, Azure SQL, PostgreSQL and Cosmos DB against consistency, query, recovery, global distribution and unit economics.

The default profile deploys no compute or database. The result is an evidence-backed decision record, not a claim of operating every service.
