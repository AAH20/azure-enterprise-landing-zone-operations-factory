# Lab 4: Monitoring and recovery

1. Verify Log Analytics provisioning and retention.
2. Design diagnostic settings for control-plane and workload logs.
3. Write KQL for deployment failures, denied policy operations and resource-health events.
4. Define alert severity, ownership, acknowledgement and escalation SLOs.
5. Set workload RPO/RTO, select backup/replication controls and execute a restore when a stateful workload is added.
